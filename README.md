## 🌟 Key Features & Action Buttons

- **Call the Clinic**: Direct telephone dialing (`tel:+918922231777`).
- **WhatsApp Integration**: Instant chat link to WhatsApp (`wa.me/918922231777`).
- **Get Directions**: Direct Google Maps directions link for Satya Sai Complex, Raja Bazaar / A.G. Road, Vizianagaram.
- **Interactive Popup Calendar**: Patients select appointment dates & specialist free time slots (Morning: 9:00 AM–12:15 PM, Evening: 2:00 PM–8:15 PM) with real-time slot availability.
- **Automated SMTP Email Dispatch**: Built-in Nodemailer integration sending HTML booking receipts directly to patient inboxes.
- **Booking Status Lookup**: Patients can check their scheduled appointment status anytime using their Booking Reference ID (e.g. `GORANTLA-839201`) or Phone Number.
- **Full Mobile Responsiveness**: Touch-friendly buttons, fluid layouts, and mobile-optimized modals.

## 🚀 Local Setup & Deployment

1. **Install dependencies**:
   ```bash
   npm install
   ```
2. **Run local server**:
   ```bash
   npm run dev
   ```
3. **Production Build**:
   ```bash
   npm run build
   ```
